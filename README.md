The Mechanic: Hybrid Possession

This project implements a Hybrid Possession mechanic to traverse through a stage.
It allows seamless possession between possessable objects and characters alike

## How do I use the mechanic?

	1. **Right click**, transitioning into first person mode.
	2. Hold **left click**, starting the line-trace.
	3. If the line-trace hits a valid target it will progress the possession (displayed in logs), but if you look away, possession cancels.
	4. When complete your camera will be smoothly blended to the new perspective point.
	5. From there you can repeat the process to other possessable actors.

## What can I possess?
	1. **Green cubes**: These can be pushed but not controlled
	2. **Green cylinders**: These cannot be pushed or controlled
	3. **Characters**: These can be controlled


I have created a simple level to demonstrate the mechanic.

## What is in the level?
	-Platforming section
	-Physics puzzle section
	-Chain possession sections
	-Green cylinders
	-Green cubes
	-Characters

## Controls
	**WASD** - Walk
	**Mouse Movement** - Look
	**Space** - Jump
	**Left Click** - Possess
	**Right Click** - Aim
